# Archive

Not built. Kept for reference and for the history attached to these files.

## `home-widgets/`

The Academic v4 `content/home/*.md` page-builder widgets, as they were
immediately before the Hugo Blox migration. Superseded by `content/_index.md`.

Four were already inactive when the migration ran (`active = false`) and have
no equivalent on the new landing page: `demo` (blank), `skills` (featurette),
`experience`, and `accomplishments`. They are parked here rather than deleted
so they can be reinstated as Hugo Blox blocks if the lab wants them —
`resume-experience`, `resume-skills`, and `resume-awards` are the counterparts.
